01Principles

→Control

Software that does what you tell it and nothing you didn't. No telemetry you can't inspect, no defaults you can't change, no layers wedged between you and the machine.

→Focus

One job, done properly. Each tool has a sharp edge and a clear boundary, built to solve a real problem, not to grow into a platform that solves none of them well.

→Clarity

Open source, all the way down. The code is the documentation of record; if you want to know exactly what a tool does, you can read it and build it yourself.

03About

Meridian Software Systems is a California LLC building open-source systems software: the infrastructure layer, from the kernel up to the desktop. Founded in 2026, everything we ship is built in public on GitHub.

The work spans an operating system, a from-scratch microkernel, driver tooling, and a bootable rescue environment. Different problems, one thread running through all of them: give the person at the keyboard real control over their machine.
